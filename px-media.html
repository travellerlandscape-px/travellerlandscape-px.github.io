px-media – how it works

px-media is a private, single-user tool. It is used only by the owner of the YouTube channel P-X Travel (@p-x-travel) to publish his own travel and drone footage. It is not offered to any other user.

Workflow

  1. The channel owner uploads his own video clips and royalty-free music (YouTube Audio Library) to a private folder in his own Google Drive.
  2. A scheduled job (GitHub Actions, owned by the channel owner) reads the next clip from that folder (Drive API, read-only).
  3. The clip is edited automatically into a vertical Short: cropping to 9:16, colour correction, zoom, text overlays and music.
  4. The finished video is uploaded to the owner's own channel with videos.insert (YouTube Data API v3), including title, description and tags.
  5. Once a week, the owner's own channel statistics are read with the YouTube Analytics API to plan the next uploads.

APIs and scopes

  • YouTube Data API v3 – youtube.upload, youtube (upload and manage the owner's own videos)
  • YouTube Analytics API – yt-analytics.readonly (the owner's own channel statistics)
  • Google Drive API – drive.readonly (the owner's own source clips)

Expected volume: 1–3 uploads per day.

Data handling

Only the owner's own data is accessed. No data of other users is collected, stored, sold or shared. Credentials are stored as encrypted secrets and can be revoked at any time at https://myaccount.google.com/permissions. See the Privacy Policy and Terms of Service.
